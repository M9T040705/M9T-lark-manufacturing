## 多租户隔离

采用**共享库 + 行级隔离**策略：

- 所有业务表均带 `tenantId` 字段
- 登录时按"企业编码 + 账号 + 密码"认证，JWT 中携带 tenantId
- 每个查询强制过滤 `tenantId`
- 超级管理员（super_admin）可跨租户

## 部门智能体隔离

双 schema 硬隔离，不依赖大模型自觉：

```
用户提问 → 解析部门（角色/群绑定）
    ↓
工具白名单过滤（只暴露本部门工具）
    ↓
LLM 选择工具 + 参数
    ↓
执行前二次校验（isToolAllowed）
    ↓
工具内部强制 tenantId + 限条数 + 安全字段
    ↓
组装回答（仅本部门数据）
```

## RAG 知识库流水线

```
文档上传 → 格式解析 → 清洗去重 → 智能切片(重叠窗口)
    ↓
元数据绑定(部门/来源/章节路径) → 向量化(bge-m3)
    ↓
存储(原文+向量+关键词) → 双路召回(关键词+向量)
    ↓
重排序 → 组装上下文 → LLM 生成回答 → 溯源标注
```

## 订阅计费状态机

```
                    开通/续费
                       ↓
┌────────┐  到期   ┌──────────┐  7天宽限  ┌──────────┐
│ active │ ──────→ │ read_only│ ────────→ │suspended │
│(正常)  │         │ (只读)   │           │ (停用)   │
└────────┘         └──────────┘           └──────────┘
     ↑                  │                      │
     └──── 续费 ────────┴──────────续费────────┘
```

- 到期前 7/3/1 天：站内通知提醒
- 到期当天：自动降级只读，设 7 天宽限期
- 宽限期结束：自动停用
- 自动续费开启：到期当天自动续 1 个月

## 飞书集成

```
飞书群 @机器人 → 事件回调(im.message.receive_v1)
    ↓
按 chat_id 匹配部门 → 部门智能体回答
    ↓
飞书 API 回复到同一群
```

- SSO 登录：code → 飞书用户信息 → 匹配系统账号（openId/手机号/姓名）
- 业务预警：低库存/交期延期/待审批 → 群机器人 webhook 推送（1小时去重）
- 多维表：租户自建应用凭证 → 读取智能表记录 → 转为部门查询工具

## 安全设计

| 层面 | 措施 |
| --- | --- |
| 认证 | JWT 双令牌，refreshToken 7天，accessToken 2h自动刷新 |
| 登录安全 | 5分钟内失败5次锁定15分钟 |
| 授权 | RBAC 9种角色 + 32个细粒度权限点 |
| 数据隔离 | 租户行级隔离 + 部门工具白名单 + 执行前二次校验 |
| 敏感数据 | 手机号/身份证/邮箱/金额脱敏工具 |
| 审计 | 所有写操作自动记录操作日志 |
| 限流 | 滑动窗口限流（登录10次/分） |
| 密钥 | 飞书 appSecret 等不回传明文，回显为 ****** |
